# CrossGEN

Cross-city traffic forecasting with limited target training-node coverage.

## Contents

- `main.tex` / `main_zh.tex`: LaTeX source of the manuscript (English / Chinese)
- `main.pdf` / `main_zh.pdf`: compiled PDFs
- `images/`: architecture figure
- `image/`: experimental figures and plotting scripts

## Build

Compile with Tectonic or XeLaTeX:

```
tectonic --untrusted main.tex
tectonic --untrusted main_zh.tex
```
